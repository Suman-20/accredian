# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/accredian-clone.git
```

Move into project

```bash
cd accredian-clone
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

# 📡 API Integration

A mock API has been implemented using Next.js API Routes.

API Endpoint

```
POST /api/enquiry
```

The API receives form data and returns a success response.

Example Response

```json
{
  "success": true,
  "message": "Enquiry submitted successfully"
}
```
